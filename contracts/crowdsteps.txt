PRACTICAL 11 - Q2: CROWDFUNDING CONTRACT (Remix IDE)
=====================================================
 
Tool: Remix IDE (https://remix.ethereum.org) - no Truffle, Ganache or MetaMask needed.
 
 
STEP 1: Create the file
-----------------------
1. Open https://remix.ethereum.org
2. In File Explorer, right-click the "contracts" folder > New File
3. Name it: Crowdfunding.sol
4. Paste this code:
 
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.21;
 
contract Campaign {
    address public owner;
    uint public goal;
    uint public deadline;
    uint public totalFunds;
 
    constructor(uint _goal, uint _durationSeconds) {
        owner = msg.sender;
        goal = _goal;
        deadline = block.timestamp + _durationSeconds;
    }
}
 
contract Crowdfunding is Campaign {
    mapping(address => uint) public contributions;
    bool public goalReached;
 
    event ContributionReceived(address contributor, uint amount);
    event GoalReached(uint totalFunds);
 
    constructor(uint _goal, uint _durationSeconds) Campaign(_goal, _durationSeconds) {}
 
    function contribute() public payable {
        require(block.timestamp < deadline, "Campaign ended");
        require(msg.value > 0, "Send some ETH");
        contributions[msg.sender] += msg.value;
        totalFunds += msg.value;
        emit ContributionReceived(msg.sender, msg.value);
 
        if (totalFunds >= goal && !goalReached) {
            goalReached = true;
            emit GoalReached(totalFunds);
        }
    }
 
    function refund() public {
        require(block.timestamp >= deadline, "Campaign still running");
        require(totalFunds < goal, "Goal reached, no refund");
        uint amount = contributions[msg.sender];
        require(amount > 0, "Nothing to refund");
        contributions[msg.sender] = 0;
        totalFunds -= amount;
        payable(msg.sender).transfer(amount);
    }
}
 
 
STEP 2: Compile
---------------
1. Click the Solidity Compiler icon (the "S" icon) on the left.
2. Set Compiler to 0.8.21.
3. Click "Compile Crowdfunding.sol" and wait for the green tick.
 
 
STEP 3: Open Deploy & Run
-------------------------
1. Click the Deploy & Run Transactions icon (Ethereum icon) on the left.
2. Environment: Remix VM (any version).
3. Contract dropdown: select "Crowdfunding" (NOT Campaign).
 
 
RUN 1: GOAL REACHED
===================
1. Next to the orange Deploy button, enter:   100, 300
   (goal = 100 wei, duration = 300 seconds = 5 minutes)
2. Click Deploy.
3. Open the contract under "Deployed Contracts" at the bottom.
4. Click "goal" -> shows 100.
5. In the VALUE box (above Deploy), type 60 and select "Wei".
6. Click "contribute" (red button).
   -> Console: open the transaction > logs -> ContributionReceived (amount 60)
7. Click "totalFunds" -> shows 60.
8. Set VALUE to 40 Wei and click "contribute" again.
   -> Logs show ContributionReceived (amount 40) AND GoalReached (100)
9. Click "totalFunds" -> shows 100.
10. Click "goalReached" -> shows true.
 
Screenshot: the logs with GoalReached, and totalFunds = 100.
 
 
RUN 2: REFUND (goal not reached)
================================
1. Deploy Crowdfunding AGAIN, this time with:   100, 60
   (goal = 100 wei, duration = 60 seconds = 1 minute)
2. Open the NEW contract under Deployed Contracts.
3. Set VALUE to 30 Wei and click "contribute".
4. Click "totalFunds" -> shows 30.
5. Click "refund" immediately (VALUE back to 0).
   -> Console shows error: "Campaign still running"   (screenshot this)
6. Wait 1 minute.
7. Click "refund" again.
   -> Transaction succeeds.
8. Click "totalFunds" -> shows 0.
9. Click "contributions" with your account address -> shows 0.
 
Screenshot: the "Campaign still running" error and totalFunds = 0 after refund.
 
 
COMMON PROBLEMS
===============
- "Send some ETH"            -> VALUE box was 0. Enter an amount and select Wei.
- "Campaign ended"           -> Deadline passed. Deploy again with a longer duration.
- "Goal reached, no refund"  -> Refund only works if the goal was NOT reached. Use Run 2.
- "Nothing to refund"        -> This account did not contribute. Use the same account that contributed.
- Wrong contract deployed    -> Contract dropdown must show "Crowdfunding", not "Campaign".
- Forgot to reset VALUE      -> Set VALUE back to 0 before clicking refund.
