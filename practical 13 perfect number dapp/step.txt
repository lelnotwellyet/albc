Practical 13: Perfect Number DApp with Truffle and Ganache (Windows)
Nov 19, 2026 · @arvind

This practical deploys a PerfectNumber smart contract to Ganache with Truffle, tests it, and checks numbers from a web page through MetaMask. Output: 4 passing tests, and 6 gives "6 is a Perfect Number!" The original aim of Practical 13 uses Hardhat; this is the same program done with Truffle and Ganache, like Practicals 7 to 9.

==============================================================================
Setup
==============================================================================
If you already did Practicals 7 to 9 with Ganache, Steps 1, 3 and 4 are done: just start Ganache (Step 2) and check MetaMask is on Ganache with the 100 ETH account. If you reopened Ganache since then, import the new first account again (Step 4).

Step 1: Install the software (skip what you already have)
1. Node.js: download the LTS version from https://nodejs.org, install it with "Add to PATH" ticked, and restart the PC.
2. VS Code: install from https://code.visualstudio.com.
3. VS Code extensions: press Ctrl+Shift+X and install Solidity (Juan Blanco) and Live Server (Ritwick Dey).
4. Ganache: download from https://archive.trufflesuite.com/ganache/ and install.
5. MetaMask: add the extension to Chrome or Firefox from https://metamask.io/download and create a wallet.
6. Truffle: open PowerShell and run the commands below. The second should show Truffle v5.x.
   npm install -g truffle
   npx truffle version

If PowerShell says running scripts is disabled, run this once and type Y:
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Step 2: Start Ganache
1. Open Ganache from the Start menu.
2. Click QUICKSTART (Ethereum).
3. Check the top bar: RPC SERVER is HTTP://127.0.0.1:7545 and NETWORK ID is 5777.
4. Keep Ganache open until you finish.

Step 3: Add the Ganache network to MetaMask
1. Click the MetaMask fox and unlock it.
2. Click the network dropdown at the top left.
3. Click Add a custom network (older versions: Add network, then Add a network manually).
4. Fill in the form:
   Field                Type exactly
   -------------------------------------------------
   Network name         Ganache
   Default RPC URL      http://127.0.0.1:7545
   Chain ID             1337
   Currency symbol      ETH
   Block explorer URL   leave empty
5. Click Save, then select Ganache in the network dropdown.

Step 4: Import a Ganache account into MetaMask
1. In Ganache, on the ACCOUNTS tab, click the key icon at the right end of the first account.
2. Copy the PRIVATE KEY from the popup.
3. In MetaMask, click the account name at the top.
4. Click Add account or hardware wallet, then Import account.
5. Paste the key and click Import.
6. The account now shows 100 ETH.

==============================================================================
Build, test and deploy
==============================================================================

Step 5: Create the Truffle project
   cd C:\Users\HP\blockchain
   mkdir prac13-truffle
   cd prac13-truffle
   npx truffle init
   code .

VS Code opens with the folders contracts, migrations, test and the file truffle-config.js.

Step 6: Write the contract: contracts\perfectnumber.sol (or contracts\perfect.sol)
Right-click the contracts folder, choose New File, name it perfectnumber.sol (or perfect.sol), paste, and press Ctrl+S.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.21;

contract PerfectNumber {
    function isPerfect(uint256 n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        uint256 sum = 1;
        for (uint256 i = 2; i <= n / i; i++) {
            if (n % i == 0) {
                sum += i;
                uint256 pair = n / i;
                if (pair != i) {
                    sum += pair;
                }
            }
        }
        return sum == n;
    }
}

Step 7: Write the migration: migrations\1_deploy.js
The file name must start with a number, and the name in artifacts.require must match the contract name PerfectNumber.

const a = artifacts.require("PerfectNumber");

module.exports = function (deployer) {
    deployer.deploy(a);
};

Step 8: Edit truffle-config.js
Open truffle-config.js, press Ctrl+A then Delete, paste this, and press Ctrl+S. Replacing the whole file avoids a stray docker: true line.

module.exports = {
  networks: {
    development: {
      host: "127.0.0.1",
      port: 7545,
      network_id: "*"
    }
  },

  compilers: {
    solc: {
      version: "0.8.21",
      settings: {
        optimizer: {
          enabled: false,
          runs: 200
        },
        evmVersion: "paris"
      }
    }
  }
};

Step 9: Compile
Open the VS Code terminal (Ctrl+`) and run:
   npx truffle compile

Expected output:
Compiling your contracts...
> Compiling .\contracts\perfectnumber.sol
> Compiled successfully using:
   - solc: 0.8.21

Step 10: Write the test: test\perfectNumber.js
Right-click the test folder, choose New File, name it perfectNumber.js, paste, and press Ctrl+S.

const PerfectNumber = artifacts.require("PerfectNumber");

contract("PerfectNumber", () => {

    it("should identify 6 as perfect", async () => {
        const p = await PerfectNumber.deployed();
        assert.equal(await p.isPerfect(6), true);
    });

    it("should identify 28 as perfect", async () => {
        const p = await PerfectNumber.deployed();
        assert.equal(await p.isPerfect(28), true);
    });

    it("should identify 10 as not perfect", async () => {
        const p = await PerfectNumber.deployed();
        assert.equal(await p.isPerfect(10), false);
    });

    it("should reject 1 as a perfect number", async () => {
        const p = await PerfectNumber.deployed();
        assert.equal(await p.isPerfect(1), false);
    });
});

Step 11: Run the tests
Ganache must be open.

Frontend and run

Step 13: Create the frontend
Right-click the empty area in Explorer (the project root), choose New Folder, and name it frontend. Create these two files inside it.

frontend\index.html:
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Perfect Number Checker</title>
</head>
<body>

    <h1>Perfect Number Checker</h1>
    <p>Decentralized application using Ethereum</p>

    <input type="number" id="num" placeholder="Enter a positive integer">
    <button onclick="checkPerfect()">Check Number</button>

    <p id="result"></p>

    <script src="https://cdn.jsdelivr.net/npm/web3@4.16.0/dist/web3.min.js"></script>
    <script src="app.js"></script>

</body>
</html>

frontend\app.js:
(Paste your contract address from Step 12 on the first line)

const contractAddress = "0x0eA0a5024FEb3558928F74e34caACd4cdab6532B";

const contractABI = [
    {
        "inputs": [
            { "name": "n", "type": "uint256" }
        ],
        "name": "isPerfect",
        "outputs": [
            { "name": "", "type": "bool" }
        ],
        "stateMutability": "pure",
        "type": "function"
    }
];

async function checkPerfect() {
    await window.ethereum.request({ method: "eth_requestAccounts" });

    const web3 = new Web3(window.ethereum);
    const contract = new web3.eth.Contract(contractABI, contractAddress);

    const num = document.getElementById("num").value;

    const result = await contract.methods.isPerfect(num).call();

    if (result) {
        document.getElementById("result").innerText = num + " is a Perfect Number!";
    } else {
        document.getElementById("result").innerText = num + " is NOT a Perfect Number.";
    }
}

==============================================================================
Common problems and fixes
==============================================================================
Most errors come from the config file, Ganache not running, MetaMask on the wrong network, or an old contract address.

Problem                                                             Fix
-----------------------------------------------------------------------------------------------------------------------------------------
failed to connect to the docker API on compile                      truffle-config.js has docker: true; replace the whole file with Step 8
Could not find artifacts for PerfectNumber                         The migration and test must say artifacts.require("PerfectNumber"), matching contract PerfectNumber
invalid opcode during migrate or test                               Check evmVersion "paris" in truffle-config.js, then run npx truffle migrate --reset
Could not connect to your Ethereum client                           Ganache is not open, or its port is not 7545
PerfectNumber has not been deployed to detected network             Run npx truffle test again with Ganache open; it deploys before testing
Check Number does nothing, or missing revert data in Console (F12)  MetaMask is not on Ganache (1337), or the address in app.js is wrong; fix it and refresh
Page does not connect to MetaMask                                   Open the page with Live Server or the python server, not by double-clicking
Errors after reopening Ganache                                      Quickstart resets the chain: run npx truffle migrate --reset, paste the new address, and import the new first account's key
